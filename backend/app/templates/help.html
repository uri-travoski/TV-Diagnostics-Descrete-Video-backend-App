TV Diagnostics & Stealth Media Vault Manual

Comprehensive setup guide and operating manual for both the Android TV client application and the standalone FastAPI Docker backend.

🔒 Master PIN: 482061 📝 Notes PIN: 1234 ⚡ Direct Play HTTP 206 🚨 Panic Trigger: Double-Tap BACK

1. What Is This App?

TV Diagnostics is a dual-layer media streaming ecosystem engineered for privacy and camouflage on smart televisions. On the outside, it presents itself as an innocent TV hardware diagnostic utility for measuring display resolutions, refresh rates, and network latency. Behind an authenticated gate lies a private personal video vault.

🛡️ Public Camouflage (Decoy)

Anyone opening the application or web address sees a legitimate-looking diagnostic dashboard showing network ping, display dimensions, color pattern tests, and firmware metrics. No video library or options are visible to uninvited guests.

🎬 Stealth Media Vault (Authenticated)

Entering the correct master PIN transforms the application into an ultra-fast streaming player with ExoPlayer, automated 60-second video thumbnails, symbol ratings (○, ●, ●●), letter-indexed tagging, and resume capabilities.

📸 System Overview: Complete workflow from Docker backend to discreet Android TV streaming.

2. How It Works (Security & Architecture)

The architecture consists of an Android TV Client (native Kotlin, ExoPlayer, Leanback D-pad focus) and a FastAPI Backend (Python 3.11, SQLite, ffmpeg) deployed as a Docker container.

🛡️ Security & Protection Pillars
  • Hardened Decoy Screen: All connection URLs and configuration settings have been completely stripped from the decoy screen. Unauthorized users have no way to configure or discover server endpoints.
  • Strict Master PIN (482061): Only the configured PIN code unlocks the Vault. All legacy codes (like 123456) are strictly rejected.
  • Fast 2-Second Timeout & Offline Fallback: When entering the PIN, the TV app connects with a fast 2-second timeout. If the server is offline or still mounting, the app seamlessly authenticates offline with the default PIN, so you are never locked out or stuck on a frozen loading screen.
  • Instant Panic Button: Double-tapping BACK or pressing MENU immediately terminates playback, wipes session memory, and snaps back to the decoy test screen.
  • Inactivity Auto-Lock: If a video is left paused for 15 minutes, or idle for 5 minutes after ending, the Vault automatically locks.

Unlocking the Stealth Media Vault
Authentication

To switch from the diagnostic screen into the private video vault, use one of two stealth unlock methods:

  • Method A (Button): Navigate your D-pad to the third button labeled "Enter Server Verification Code" and press OK.
  • Method B (Remote D-Pad Secret Sequence): On your remote control, press:
    UP UP DOWN DOWN LEFT RIGHT.

The Server Verification Code dialog will appear with a numeric keypad. Enter the default master PIN: 482061 and press SUBMIT (or press OK on your remote).

3
Setup Backend Server Connection
First-Time Setup

Because unauthorized viewers cannot touch server settings from the decoy screen, the backend URL configuration is located inside the Vault:

  1. Once the Vault opens, navigate to the single top row.
  2. Move focus all the way to the right to select the ⚙ Options button (located right next to the red 🔒 button) and press OK.
  3. In the Connection & Options dialog:
    • Backend Server URL: Enter your Docker backend address, for example: http://192.168.1.50:8090
    • The dialog conveniently displays your TV's detected IP address (e.g. Device IP: 192.168.1.104) so you can easily identify your local network subnet.
  4. Select Save & Connect. The dialog will close and the video library will immediately populate!
⚠️
Custom PIN Code: You can also update your Vault PIN in this dialog. If you change it here, the new PIN takes effect immediately for future logins.

Emergency Panic Button & Inactivity Auto-Lock
Stealth Defense

If someone walks into the room while you are watching a video or browsing your vault, you can activate the emergency panic defense:

🚨
EMERGENCY PANIC TRIGGER:
Press Double-Tap BACK (two rapid presses within 600ms) or press the MENU button on your remote.

Inactivity Auto-Lock: If you step away and leave a video paused, the app will automatically lock after 15 minutes. If a video finishes playing and no button is pressed, the app locks after 5 minutes.

7
Discreet Video Notes (4-Digit PIN)
Privacy Tier

Video notes allow you to keep private logs or synopsis for individual videos. To protect them even while someone is viewing the vault:

  1. Open ⚙ Options from the top bar.
  2. Under Video Notes Visibility, toggle the switch to ON.
  3. Enter the 4-digit Notes PIN: 1234.
  4. When verified, notes are revealed in the Video Detail dialog. When toggled OFF, notes are completely hidden.

4. Backend Management & Web Console

The backend provides a desktop web console accessible from any PC, Mac, tablet, or smartphone connected to the same local network:
http://<server-ip>:8090/admin

🖥️ Browser Direct Play

Watch any video in your library directly within Chrome, Firefox, Safari, or Edge with smooth HTTP 206 byte-range streaming and saved resume points.

🏷️ Letter-Indexed Tags

Type any letter into the tag combobox to instantly view all matching tags. Add or remove tags on any video card with live update.

✏️ Real Disk File Renaming

When you edit a video title in the web admin console, the backend does not just update the SQLite database — it automatically renames the real file on your hard drive / SMB share while safely preserving the file extension (e.g. .mp4, .mkv).

💾
Zero-Loss Database Backups: Before every title edit or metadata change, the backend creates an automatic hot snapshot backup of the database in backend/data/db/backups/.

5. Standalone Docker Deployment

The backend is fully containerized and hosted on the GitHub Container Registry (ghcr.io). No Python or build tools are required on the host system.

Here is your standalone docker-compose.yml:

services:
  tv-diagnostics-backend:
    image: ghcr.io/uri-travoski/tv-diagnostics-backend:latest
    container_name: tv-diagnostics-backend
    restart: unless-stopped
    ports:
      - "8090:8090"
    environment:
      - PIN_CODE=482061            # Default master PIN for TV Vault
      - NOTES_PIN=1234             # 4-digit PIN for Video Notes
      - PORT=8090
      - SCAN_ON_STARTUP=true
      - SCAN_INTERVAL_MINUTES=30
      - MOUNT_POLL_INTERVAL_SECONDS=5
      - VIDEO_DIRS=/videos
    volumes:
      # Map your host or SMB video storage to /videos
      - /path/to/your/movies:/videos
      
      # Persistent storage for metadata database and thumbnails
      - ./data:/app/data

To run the container:

# Start the service in the background
docker-compose up -d

# View container logs
docker-compose logs -f

7. Troubleshooting & FAQ

❓ The TV app cannot connect to the backend server

1. Ensure the TV and Docker host are connected to the same local Wi-Fi or LAN network.
2. Check your host firewall: Port 8090 TCP must be open.
3. In the TV app, click ⚙ Options and make sure the URL is formatted as http://<host-ip>:8090 (use the IP address, not localhost).

❓ Can I change the master PIN code?

Yes! Open ⚙ Options inside the TV vault, change the Vault PIN Code field, and click Save & Connect. Alternatively, specify PIN_CODE=yourpin in your docker-compose.yml.

❓ What happens if an external drive unmounts?

The backend features an automatic Mount Watcher with poll intervals. If your external hard drive or SMB share disconnects, the server displays an amber notice in the admin console and keeps your database safe without deleting missing files. As soon as the drive re-mounts, it automatically resumes streaming!
